# Task 6.1 — Git workflow

- git status — Checks the current state of the repository and shows modified or staged files.
- git add — Stages selected changes for the next commit.
- git commit — Saves staged changes as a checkpoint in Git history.
- git log --oneline -5 — Displays the five most recent commits in a compact format.


My understanding:
Git tracks changes made to files in a project. Staging selects which changes should be included in a commit, while committing saves those changes in the repository's history. Git history helps us review previous work
