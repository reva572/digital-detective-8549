## Running the Number Converter

The number converter is written in Python and converts a decimal number into binary and hexadecimal representations.

To run it:

1. Open Terminal in the repository folder.
2. Run:

   ```bash
   python3 mission-05-numbers-data/number_converter.py
   ```

3. Enter a decimal number when prompted.
4. The program displays its binary and hexadecimal representations.
