# The Digital Detective
## About This Project

The Digital Detective is an independent learning assignment focused on understanding how computers work, exploring operating systems, practising command-line operations, learning number systems, and understanding computer networks.

This repository contains the work completed across nine missions, with each mission documented separately.

## Mission Index

| Mission | Topic |
|---|---|
| 00 | Repository and Workspace Setup |
| 01 | Computer Fundamentals and IPOS |
| 02 | Terminal and File Management |
| 03 | Operating Systems |
| 04 | How Programs Run |
| 05 | Number Systems and Data Representation |
| 06 | Git and GitHub |
| 07 | Computer Networking |
| 08 | Final Report and Submission |

## Technologies and Tools

- macOS Terminal
- Python 3
- Git
- GitHub
- Markdown

## Repository Structure

Each mission has a separate folder containing its README and relevant work. The `evidence/` folder stores privacy-safe screenshots and outputs.

## Learning Outcomes

Through this assignment, I aim to understand computer fundamentals, practise Terminal commands, explore operating-system functions, learn how programs execute, understand data representation, and gain practical experience with Git and GitHub.

## Project Progress

Each mission will be documented, committed, and pushed separately to maintain a clear record of progress.
