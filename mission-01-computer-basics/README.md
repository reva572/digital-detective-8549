# Task 1.1 — Trace One Activity Using IPOS 

# Stage 1 : Input
When i press a letter on my keyboard, the pressed key converts into a digital signal, the signal is sent to a computer, the computer then receives the signal and interprets it as input 
The hardware involved is Keyboard

# Stage 2 : Processing
CPU is the brain of the computer. It processes the input and asks the application, like im using VS code right now to display what i typed.
Every CPU has an individual processing unit called the CORE. The operating system manages communication between the hardware and the software and its core component which is KERNEL manages system resources and facilitates communication between applications and hardware through system services and device drivers and RAM temporarily stores the running application's data

Hardware involved: CPU and RAM.
Software involved: Operating system and kernel

# Stage 3 : Output
Through CPU the processed information is sent to the display system and letter appears on the screen

GPU helps convert the information about text, position, font or appearance into graphical data that can be displayed and the the graphic hardware sends it to the display through display connection
and the monitor displays the output

# Storage
Seeing text on the screen does not mean it has been permanently saved. Like im typing in VS code, so the working data is temporarily held by the RAM, to save the file i need to press (Command+S), and then the document is stored in the permanent storage which is SSD


## Task 1.2 — Identify Hardware and Software


Keyboard

- Item: Keyboard
- Hardware/Software: Hardware
- Software Type: Not applicable
- Purpose: Used to enter text, numbers and commands into the computer

Trackpad

- Item:Trackpad
- Hardware/Software: Hardware
- Software Type: Not applicable
- Purpose: Used to move the pointer, select items and interact with the computer.

CPU

- Item: CPU
- Hardware/Software: Hardware
- Software Type: Not applicable
- Purpose: Executes instructions and performs calculations.

SSD

- Item: SSD
- Hardware/Software: Hardware
- Software Type: Not applicable
- Purpose: Stores files, applications and the operating system.

macOS

- Item:macOS
- Hardware/Software: Software
- Software Type: Operating System Software
- Purpose: Manages hardware, memory, files and applications.

VS Code

- Item: VS Code
- Hardware/Software: Software
- Software Type: Application Software
- Purpose: Used to write and edit source code.

Google Chrome

- Item: Google Chrome
- Hardware/Software: Software
- Software Type: Application Software
- Purpose: Used to browse websites and access information.

Disk Utility

- Item: Disk Utility
- Hardware/Software: Software
- Software Type: Utility Software
- Purpose: Used to manage disks and check storage devices.



# Task 1.3 — Computer Systems Around You

ATM (Automated Teller Machine)

- Main Purpose: Allows customers to withdraw cash, check account balances and perform banking transactions
- One Input: ATM card and PIN entered by the user
- One Output: Cash dispensed or transaction details displayed on the screen

Smart TV

- Main Purpose: Used to watch television programmes, stream online content and access applications
- One Input: Commands given through the remote control
- One Output: Video and audio displayed through the screen and speakers

Traffic Signal System

- Main Purpose: Controls vehicle and pedestrian movement to maintain road safety and manage traffic
- One Input: Data received from vehicle sensors or timers
- One Output: Red, yellow and green signals displayed to road users
