# TASK 4.2 - Compare compiler and interpreter 

Compiler vs Interpreter

When translation / execution happens-
- Compiler: Translates the source code before execution.
- Interpreter: Executes the source code at runtime.

Typical output-
- Compiler: Often produces machine code or an executable form.
- Interpreter: Executes instructions and produces results.

One example-
- Compiler: C and C++
- Interpreter: Python

One advantage-
- Compiler: Compiled programs can run efficiently
- Interpreter: Convenient for testing and debugging

# Difference between Compiler and Interpreter
A compiler translates source code into another form(machine code), before the program runs. 
An interpreter executes instructions at runtime. 
Compiled programs can run efficiently, while interpreters make testing and debugging convenient. C and C++ are commonly compiled languages, whereas Python is commonly described as an interpreted language
